# Travel Maximizer

Live award date matrix: https://iansimp.github.io/travel-maximizer/

Original dashboard archive: https://iansimp.github.io/travel-maximizer/old/

The original dashboard is preserved unchanged from commit 7c94ad95ebb6525d52a82b7f0398b663f55f4ddd. Future legacy exports publish separately under /old/latest/.

The matrix uses captured Seats.aero leads, logged AwardTool examples and 49 Delta round-trip quotes from October 5–6, 2026. Date sliders and airline filters recalculate locally; they do not request fresh inventory. Select a cell for booking programs, taxes and seat evidence. Basic/Light fare restrictions and airline availability require verification.

Source and collection tools remain in the private iansimp/cursor repo under travel-maximizer/. The matrix source is dashboard/matrix.html. Never publish API keys or airline credentials.

Do not book from this page. Verify on the airline site.
